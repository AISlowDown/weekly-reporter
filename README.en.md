A Codex skill that turns Computer History records or your own work notes into project-based academic weekly reports.

## What it does

- Groups literature, data, code, papers, presentations, and administrative tasks by project.
- Lets you review and select candidate activities in the conversation before generating a report.
- Produces daily activity views, retrospective Gantt-style tables, and time charts with clearly labeled estimates when requested and supported by records.
- Saves HTML and Markdown, with optional Obsidian archiving to your chosen location.

## Get started

Download the [skill package](dist/computer-history-weekly-report-public.zip), extract it, and place the `computer-history-weekly-report/` folder in your environment's skill directory or follow its supported installation workflow.

> Use $computer-history-weekly-report to review last week's research activities. Group candidates by project and let me choose in this conversation. Then generate an HTML report with daily activities and approximate time spent, ordered by total project time.

## Requirements and privacy

Computer History requires a compatible environment and existing records. This package does not include a recorder or enable recording. You can supply activity logs instead. Selection controls depend on the host; numbered replies are an alternative. Obsidian archiving requires local access and a destination you provide.

Time estimates are not exact working hours. Generating or saving a report does not publish it. The public package contains generic instructions and fictional examples, not personal activity records.
